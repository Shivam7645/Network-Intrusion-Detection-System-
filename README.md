# Network Intrusion Detection System (NIDS)

This project focuses on creating a Network Intrusion Detection System (NIDS) using machine learning techniques. The system is designed to detect malicious activities and threats within a network, achieving an impressive accuracy of 99.97%.

## Project Overview

The Network Intrusion Detection System (NIDS) monitors network traffic for suspicious activities and potential threats. By leveraging machine learning algorithms, the system can classify network behavior as either normal or malicious, helping to protect networks from cyber threats.

## Features

- **Data Preprocessing**: Includes data cleaning, normalization, and feature extraction to prepare the network traffic data for modeling.
- **Machine Learning Models**: Various machine learning models are tested and evaluated, with the best-performing model achieving 99.97% accuracy.
- **Real-time Detection**: The system can be integrated into network environments to provide real-time intrusion detection.
- **Detailed Evaluation**: The model's performance is evaluated using metrics such as accuracy, precision, recall, and F1-score.
